## 🛠️ Descripción del Sistema
Sistema en C++ enfocado en la gestión integral de un taller mecánico. Utiliza una arquitectura de dos capas (lógica vs. presentación) y gestión de memoria dinámica mediante arreglos redimensionables (factor de crecimiento de 2x) para vehículos, mecánicos, repuestos y órdenes de servicio.
